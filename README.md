# 社区舆情看板

独立的 Discord 社区舆情网页。数据来自 `data/舆情.xlsx` 的周反馈表。

1. **整体舆情** — 多周累计、跨周反复主题，以及对应的产品建议和运营动作
2. **本周概览** — 点「查看一周」后选定日期，看该周主线和当周可做的事
3. **高频议题** — 该周类型、改法、运营后续
4. **原话摘录** — 表里的玩家原文

首页不铺日期列表。重新导入表格：

```bash
python3 scripts/import-xlsx.py
```

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:3847](http://127.0.0.1:3847)。
