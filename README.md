# 社区舆情看板

由 **ICY** 搭建的 Discord 社区舆情网页。数据来自 `data/舆情.xlsx` 的周反馈表。

1. **整体舆情** — 多周累计、周反馈量、跨周反复出现的主题
2. **本周概览** — 点「查看一周」后选定日期，看该周主线
3. **高频议题** — 该周全部反馈类型与占比
4. **建议与动作** — 每类对应的产品改法，以及运营这周能做的事
5. **原话摘录** — 表里的玩家原文

首页不铺日期列表。重新导入表格：

```bash
python3 scripts/import-xlsx.py
```

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:3847](http://127.0.0.1:3847)。
