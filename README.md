# 社区舆情看板

独立的 Discord 社区舆情网页。舆情按周更新，先看整体，再看某一周。

1. **整体舆情** — 多周累计、周度情绪、跨周未关议题
2. **本周概览** — 选中周次的主线、判断、分类和日情绪
3. **高频议题** — 该周重复出现的问题
4. **原话摘录** — 可引用的社区原话和处理进度

右上角切换周次，只替换本周及以下栏目；整体大盘保持不变。数据在 `src/lib/data.ts`。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:3847](http://127.0.0.1:3847)。

## 技术

Next.js、TypeScript、Tailwind CSS、shadcn/ui。
