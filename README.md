# 社区舆情看板

独立的 Discord 社区舆情网页。版式参考杂志式目录页：浅底点阵、衬线标题、章节大数字、双栏卡片。

页面按一张完整网页来排，目录从 01 起：

1. **本周概览** — 主线、判断、指标、情绪弧线
2. **反馈分类** — 缺陷 / 建议 / 吐槽 / 好评
3. **高频议题** — 重复出现的问题，可点进对应原话
4. **原话摘录** — 可引用的社区原话，以及处理进度

数据来自周报里「收集反馈」那一类内容，做成可筛选的看板。换成自己的周报时，改 `src/lib/data.ts` 即可。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:3847](http://127.0.0.1:3847)。

## 技术

Next.js、TypeScript、Tailwind CSS、shadcn/ui。
