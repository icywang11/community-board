# 社区舆情看板

Discord 社区周报里「四、收集反馈」这一段的网页看板。版式参考杂志式目录页：浅底点阵、衬线标题、章节大数字、双栏卡片。

本页只做反馈收集，不铺完整周报。

## 能看到什么

- **目录**：本周反馈按缺陷 / 建议 / 吐槽 / 好评归类
- **本周主线与判断**：先看叙事，再看数字
- **情绪弧线**：一周里负向占比如何起伏
- **高频议题**：重复出现的问题，可点进对应原话
- **处理闭环**：待确认 → 已记录 → 已同步研发 → 已回复社区 → 关闭
- **原话摘录**：Discord 线程里抽出的可引用句子，支持搜索和筛选

数据是按周报「收集反馈」结构整理的示例周（第 35 周 / 第 34 周），方便直接预览交互。换成你们自己的周报时，改 `src/lib/data.ts` 即可。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:3847](http://127.0.0.1:3847)。

## 技术

Next.js、TypeScript、Tailwind CSS、shadcn/ui。
