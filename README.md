# 社区舆情看板

独立的 Discord 社区舆情网页。数据来自 `data/舆情.xlsx` 的周反馈表。

1. **整体舆情** — 多周累计、周反馈量、跨周反复出现的主题
2. **本周概览** — 选中周次的主线、判断、当周前四类型
3. **高频议题** — 该周全部反馈类型与占比
4. **原话摘录** — 表里的玩家原文

右上角切换周次，只替换本周及以下栏目。重新导入表格：

```bash
python3 scripts/import-xlsx.py
```

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:3847](http://127.0.0.1:3847)。
